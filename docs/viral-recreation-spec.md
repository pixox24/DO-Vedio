# 爆款复创：首版页面与交互规格

日期：2026-10-11。状态：用户已确认并授权实施；完成和验证状态见实施记录。

本文将已确认需求细化为页面布局、字段、按钮行为与验收标准，作为首版实施依据。

实施分工见 [Agent 任务计划](./viral-recreation-tasks.md)，固定模型、推理强度与修改范围见 [Sol 6.1 配置说明](./agent-config/README.md)，实际证据见 [实施记录](./viral-recreation-status.md)。

## 1. 已确认的产品范围

| 项目 | 首版范围 |
| --- | --- |
| 首页入口 | 将「分析爆款」改为「爆款复创」，用户提供参考稿 |
| 功能载体 | 独立复创页面，包含快捷复创、原创工作台 |
| 参考输入 | 一篇粘贴文本 |
| 快捷复创 | 自动拆解、构思三个新角度、选择一项、生成大纲与正文、检查；默认输出一篇完整稿 |
| 原创工作台 | 参考拆解、创作任务、角度与证据路线、个人风格、大纲与成稿、检查采用均可查看和调整 |
| 产物 | 可直接配音的视频口播稿 |
| 平台 | 抖音、小红书、B站、西瓜；每次新创作选择目标平台 |
| 制作交接 | 用户采用稿件后进入现有视频制作，从断句标注开始 |

两种模式共享输入、阶段产物、候选稿与版本。首版采集范围是用户粘贴的文本；推荐榜单、链接提取、音视频转写、多样本策略库和发布表现分析属于后续独立需求。

## 2. 页面入口与草稿组织

建议路由为 `/viral`（新建与恢复入口）、`/viral/[id]`（一份可恢复的复创草稿）。制作继续使用 `/projects/[id]/video`。

首页选择「爆款复创」后，输入框提示「粘贴想借鉴的口播文案」，发送按钮的可访问名称为「进入爆款复创」。输入为空也可进入独立页面；已有文本带入参考稿字段。首页提交只进入页面，模型调用由独立页面的明确按钮启动。保留 Enter 换行、⌘/Ctrl+Enter 进入的键盘约定。参考文本不放入 URL。

独立页面默认打开快捷复创。首个有效编辑保存为复创草稿并获得稳定 URL；完全空白的访问不产生草稿或视频项目。页头提供「新建复创」「最近草稿」及保存状态。最近草稿仅提供恢复入口，首版采用简洁列表。

打开草稿后恢复输入、所处阶段、候选稿、当前选择和关联制作项目。进入制作前只保存复创草稿；第一次采用时再创建视频项目。

## 3. 页面布局

沿用现有暗色界面、亮绿强调色、字体与基础组件。编辑正文是视觉中心；主操作保持一个明确的行动目标。长文可持续滚动阅读，按钮区不得遮住正文最后几行。处理状态就近显示，失败提示留在失败的步骤内。

### 3.1 快捷复创

桌面采用左侧输入、右侧正文的两栏布局，内容宽度上限约 1440px，左右比例约 35% / 65%。

```text
页头：爆款复创 / 当前草稿名     已保存    最近草稿    新建复创
模式：[快捷复创] [原创工作台]

左：本期输入                         右：本期口播稿
参考稿（大文本框）                   空态 / 阶段进度 / 正文
自己的主题                           标题、字数、预计口播时长
目标平台 + 目标时长                  正文编辑器
自己的素材（选填，可展开）           展开：简洁拆解 / 其他角度 / 检查说明
当前风格摘要 + 更多设置              复制 / 导出 / 换个角度 / 到工作台调整
生成文案                            采用并进入视频制作
```

生成前，右侧空态说明将得到一篇完整口播稿，不重复放置大尺寸欢迎区。生成时显示真实阶段；写稿开始后逐步显示正文，标明「生成中」。完成后直接显示可编辑正文，报告与未选角度默认折叠。进入制作按钮固定在结果区底部的操作栏。

宽度低于 1024px 时单列。首次输入优先展示表单；生成后定位到结果与进度，输入区收为可展开摘要。用户主动开始编辑后，不因新状态更新强制滚动或抢焦点。

### 3.2 原创工作台

宽屏（约 1440px 及以上）采用三栏：左侧参考与拆解，中央当前创作阶段，右侧本期素材与风格；比例约 22% / 56% / 22%。一般桌面收为两栏，参考、素材与风格归入辅助栏的标签页。窄屏采用单列，辅助内容通过折叠区展开。

```text
页头与模式切换同快捷复创
阶段导航：拆解 → 创作任务 → 角度与证据 → 风格 → 大纲与正文 → 检查采用

左：参考与拆解          中：当前创作阶段             右：本期依据
参考原文               可编辑任务 / 三个角度        素材条目
原文定位与分析         可编辑大纲 / 正文             本期风格规则
可迁移机制             当前阶段的主操作             平台与时长摘要
独特表达提示
```

阶段导航允许查看已完成的阶段；后续阶段依赖未满足时说明缺少什么。正文生成后保持中央正文可读，报告在辅助区展示。切换模式仅切换视图，本次自动任务仍按照启动时的计划继续执行。

## 4. 输入字段与默认值

平台分为短口播（抖音、小红书）和中长口播（B站、西瓜）。平台每次新建时需显式选择；恢复草稿时保留该草稿选择。

| 字段 | 控件与位置 | 要求 / 默认值 | 行为 |
| --- | --- | --- | --- |
| 参考稿 | 主输入区多行框 | 非空；首版一篇，最多 20000 字符 | 显示字符数；超过上限明确提示，完整保留输入，不静默截断 |
| 参考标题 / 来源备注 | 参考框下折叠项 | 选填 | 用于识别来源；不是抓取链接入口 |
| 自己的主题 | 主输入区单行框 | 生成角度与成稿前必填；最多 200 字符 | 说明「这期你想讲什么」；参考稿不自动代替用户的主题 |
| 目标平台 | 四项选择 | 新草稿无预选 | 抖音 / 小红书 / B站 / 西瓜 |
| 目标时长 | 平台旁快捷项与自定义输入 | 短口播默认 2 分钟；中长默认 5 分钟；可设 30 秒至 30 分钟 | 短口播推荐 1–3 分钟，中长推荐 3–10 分钟；推荐范围外仍可自定义 |
| 自己的素材 | 可展开多行框；工作台可整理为条目 | 选填，最多 10000 字符 | 支持观点、案例、经历、数据与来源备注；单条来源可标为用户提供、来源待核实 |
| 目标受众 | 更多设置 / 创作任务 | 选填 | 留空按本期主题推断一般受众；推断可见、可修改 |
| 本期核心主张 | 工作台创作任务 | 系统建议，可编辑 | 表明想回答的问题与主要观点；快捷模式自动生成 |
| 内容性质 | 更多设置 / 创作任务 | 默认在真实科普与观点评论中判断 | 虚构故事必须由用户显式选择，且不能冒充个人真实经历 |
| 个人风格 | 摘要与选择器 | 优先复用用户上次选择；没有时使用已有「知识科普」模板 | 显示实际采用的风格；选择已有模板或到风格管理页调整 |
| 本期风格规则 | 工作台右栏 | 来自本次模板快照，可修改 | 修改只影响本期；事实与选定论证优先，模板不能覆盖用户已确定的新角度 |
| 叙述视角 | 更多设置 / 风格区 | 默认第三人称；可选第一人称 | 第一人称观点可表达；涉及亲身经历仍需要素材支持 |
| 语速 | 更多设置 | 跟随风格，可选 200 / 250 / 300 字每分钟 | 实时更新字数目标与预计时长；预计值不当作实际配音时长 |
| 必含要点 | 更多设置 / 创作任务 | 选填，每行一条 | 纳入角度、大纲和检查 |
| 避免内容 / 禁用词 | 更多设置 | 选填 | 当前用户明确规则作为检查项；避免复制参考稿的独特表达由比对侧处理 |
| 结尾目标 | 更多设置 / 创作任务 | 默认自然收束 | 可选讨论提问、收藏提醒、业务行动；领取资料等具体承诺需要相应素材 |
| 文字模型 | 更多设置，主按钮旁显示摘要 | 复用上次可用选择；没有时选第一个可用文本模型 | 无可用模型时保留输入，提供「去模型中心配置」入口 |
| 热梗 | 更多设置 | 首版复创默认关闭 | 可使用已有梗库中已核实、用户已指定的条目；快捷流程不插入必需的挑梗步骤 |
| 去 AI 味 | 更多设置 | 沿用已有偏好，首次默认开启 | 个人风格优先；处理后检查最终正文 |
| 制作画幅 | 更多设置中的制作设置 | 短口播默认 9:16，中长默认 16:9，可改 | 影响制作交接，不要求重新写稿 |

快捷模式常驻参考稿、主题、平台、时长；其他字段收进「补充素材」「风格与更多设置」。时长有默认值，无需额外选择；用户填写参考稿、主题并选择平台后，一次提交即可完成自动流程。

切换平台时，尚未被用户手动修改的时长与画幅随平台类别更新为默认值；用户已明确设置的值保持不变。页面摘要始终显示实际时长与画幅。新建草稿重新应用默认规则，恢复草稿保留其已有设置。

工作台允许仅凭参考稿先拆解。生成角度前，主题、平台及有效时长必须齐全。风格首次使用无需提交历史样本；现有样本提炼能力通过风格管理入口使用。

预计字数沿用仓库现有口播计数与语速换算。预计时长偏差超过目标的 ±15% 时显示校准操作，不宣称配音后会精确等于目标。

## 5. 阶段产物与生成规则

| 阶段 | 可见产物 | 允许用户做什么 |
| --- | --- | --- |
| 参考拆解 | 开头承诺、信息推进、节奏、结尾功能、原文定位；区分文本观察与作用假设 | 看对应原文、决定采用哪些通用机制 |
| 创作任务 | 自己的主题、受众、核心主张、素材与内容性质 | 编辑任务、补充素材、改平台与时长 |
| 角度与证据 | 三张角度卡，包含核心主张、示例开头、论证路线、素材依据、缺失依据 | 选择、编辑、换一批 |
| 风格 | 当前语气、视角、推荐与禁止写法、示范摘要 | 选择已有风格、修改本期规则 |
| 大纲 | 段 / 章标题、功能、要点、预计时长、素材关联 | 增删、排序、编辑；至少保留一段且每段时长为正 |
| 正文 | 新标题与分段口播正文、口播字数、预计时长 | 直接编辑、局部重写、校准时长、复制与导出 |
| 检查 | 当前正文版本的问题片段、理由、建议与修订记录 | 定位问题、修订、重新检查、采用 |

三个角度需要在核心问题、证据路线或展开方式上有实质差异。快捷模式默认选择素材支持充分、适合平台和时长的一项，并简要说明选择理由；默认只写这一项的全文。

素材不足时采用不依赖缺失素材的角度或表达。重要材料确实不可替代时在工作台提示补充；快捷模式若无法得到可用稿件，保留已有产物并显示具体缺项。

短稿优先连续口播与单一核心问题，中长稿可分章展开。开头长度和结尾互动按平台、时长与内容任务安排；不强制套用现有写稿提示词中「开场 10–20 秒、结尾点赞投币」的固定要求。

详细拆解可引用原文供用户理解。写稿阶段只接收筛选后的通用机制、本期任务、个人风格和用户素材；不接收参考全文、原作者独特比喻、独特案例、金句或逐段复原指令。独特表达记录留在比对侧。风格示范不能作为事实依据。

新稿可以使用同一主题的公共事实与常见功能结构。涉及参考稿中的具体事实，应由用户主动补入本期素材并标注来源；原文不自动成为本期可用素材。

系统不从纯文字分析推断实际镜头、配乐、观看留存或流量成因。检查报告不显示「原创率」「爆款概率」或「保证不侵权」。

## 6. 按钮行为

| 按钮 | 出现位置 | 点击行为 / 可用条件 |
| --- | --- | --- |
| 进入爆款复创 | 首页 | 打开独立页面并带入已有参考文本；不启动模型任务 |
| 快捷复创 / 原创工作台 | 页面顶部 | 切换同一草稿视图；不额外生成、不停止任务、不丢输入 |
| 生成文案 | 快捷输入区 | 必填项有效且有可用模型时，一次启动到成稿与检查的完整任务；已有稿件保留为旧版 |
| 开始拆解 | 工作台参考区 | 仅要求参考稿与可用模型；生成详细分析与可迁移机制 |
| 生成新角度 | 工作台任务区 | 任务信息齐全时，基于当前机制与本期素材生成三项候选 |
| 采用此角度 | 角度卡 | 记录当前选择；不立即覆盖已有大纲与正文 |
| 按此角度成稿 / 采用推荐并成稿 | 工作台角度区 | 已选角度时按当前选择继续完成风格、大纲、正文与检查；未选角度时按钮说明将采用系统推荐 |
| 生成大纲 | 工作台 | 按当前角度、任务与时长生成可编辑大纲 |
| 按大纲成稿 | 工作台 | 按当前有效大纲写稿并检查；保留生成前版本 |
| 编辑 / 直接编辑正文 | 正文区 | 修改当前候选稿；变更后本版本标记待检查 |
| 重写这一段 | 段落操作 | 按明确修改要求仅生成该段候选；保留旧段；人工确认采用候选后更新正文 |
| 换个角度 | 快捷结果区 | 展开未选候选；选择后明确点击「用此角度重新成稿」，不因浏览卡片自动调用 |
| 换一批角度 | 角度区 | 新增一批候选，原有选择与稿件保留；只查看不发起请求 |
| 到工作台调整 | 快捷结果区 | 切到工作台并定位当前稿件 / 当前阶段 |
| 校准时长 | 偏差提示旁 | 调整当前稿件长度，保留旧版；新结果重新检查 |
| 重新检查 | 检查区 | 检查当前正文与当前规则，替换当前版本对应的检查结果 |
| 采用并进入视频制作 | 正文主操作 | 当前稿件完整、未受上游变更影响且没有运行中的写入任务时可用；保存稿件，必要时先检查，再创建或打开关联制作项目 |
| 打开视频制作 | 当前版本已采用时 | 打开该版本关联的既有项目，不创建重复项目 |
| 更新制作设置并打开 | 正文已采用，仅制作画幅改变时 | 对关联项目明确应用新的制作设置，再进入制作；沿用制作模块的设置与更新规则，不重写正文或创建重复项目 |
| 同步新版文案 | 已有关联项目且稿件已改时 | 显示现有制作状态与更新影响；用户选择同步到原项目或保留原制作并新建项目 |
| 停止生成 | 运行阶段旁 | 停止本次任务，保留完成阶段和已生成正文；不采用未完成稿 |
| 从此步继续 | 失败 / 已停止阶段 | 输入未改变时从失败或停止位置继续；变更后从最早受影响阶段更新 |
| 复制 / 导出 Markdown | 正文次级操作 | 输出当前选定稿的标题与正文；分析报告、证据标记、检查说明不混入口播正文 |
| 恢复此稿设置 | 基于旧设置的稿件摘要 / 版本区 | 恢复该稿对应的任务、角度与本期风格设置；保留恢复前输入快照，再按恢复后的版本检查与采用 |
| 最近草稿 / 新建复创 | 页头 | 恢复已保存草稿或进入新草稿；运行任务继续归属于原草稿 |

生成中的主操作显示当前阶段并禁止重复启动。两种模式都允许查看已完成内容和停止任务。自动检查可对未经人工编辑的自动生成稿做最多一次针对性修订，修订版本必须再次检查；仍存在阻断问题时进入「需要修改」，不继续自动循环。只要该稿发生过人工编辑，检查仅给问题和修改候选，用户明确采用后才替换，即使只手改过一个段落也不整稿自动覆盖。

进入制作遇到尚待检查的稿件时，按钮显示「检查并进入视频制作」。保存或检查失败时保留当前页与正文，失败原因可见，允许重试。

## 7. 任务状态、修改与恢复

### 7.1 状态表达

显示等待开始、拆解中、构思角度、生成大纲、写稿中、检查中、已完成、需要修改、失败、已停止。单次模型调用使用流动状态条；仅在有真实可计数任务时显示任务数，不伪造总进度百分比或固定剩余时间。

每个任务绑定启动时的输入和风格快照。任务运行期间，与本次任务有关的上游字段锁定；用户可以查看与切换模式，停止后再编辑。后台任务和阶段产物持久保存，刷新后恢复同一个任务，页面离开不视为停止。

写稿、修订或检查执行期间，该任务涉及的标题和正文只读；局部重写、时长校准、重复检查及采用操作禁用。用户仍可查看旧稿、复制已有文本或停止任务。完成后才恢复编辑，检查结果始终关联检查启动时的正文版本。

已停止或失败的半稿可查看与复制；从暂停位置继续后产生完整候选稿，完成必要检查后才可进入制作。过期任务的返回结果不能覆盖较新的稿件。

### 7.2 输入修改影响

输入修改先保存，已有结果标记「基于旧设置」，不因每次打字自动重新调用。主操作明确说明将更新哪些阶段。

涉及生成内容的上游设置改变后，先更新受影响阶段，或通过「恢复此稿设置」恢复该稿对应的输入，再采用。仅重新检查不能将旧任务的正文变成本期新主题或新角度的稿件。人工修改正文只需更新检查，单独调整制作画幅也不要求重新写稿。

| 修改内容 | 需要更新的阶段 | 保留内容 |
| --- | --- | --- |
| 参考稿 | 拆解及其后的阶段 | 旧版全部产物、自己的主题与素材 |
| 主题、受众、素材、内容性质、必含要点、结尾目标 | 角度、论证、大纲、正文与检查 | 参考拆解、风格、旧稿 |
| 平台、目标时长 | 角度适配、大纲、正文与检查 | 参考拆解、用户角度选择、旧稿；不自动换掉已选角度 |
| 本期语言风格、视角 | 正文与检查 | 已选角度、证据与用户大纲 |
| 语速 | 字数目标、段落时长适配、正文与检查 | 原分析与角度 |
| 禁用词 / 避免内容 | 检查；修订时再更新正文 | 分析、角度、大纲与旧稿 |
| 选定角度、论证路线 | 大纲、正文与检查 | 分析、其他候选角度、风格与旧稿 |
| 大纲 | 正文与检查 | 分析、角度、素材与旧稿 |
| 人工修改正文 | 检查 | 其他阶段产物 |
| 制作画幅 | 制作交接设置 | 当前文案与检查结果 |
| 模型选择 | 后续新调用使用新模型 | 已完成的分析与稿件，不因换模型全部过期 |

生成任务输入更新与正文人工编辑分别记录；旧稿即使继续可读，也不会被标成已经使用最新设置生成的稿。风格模板全局更新时，本草稿保留快照；用户明确重新选择模板后才应用新版本。

## 8. 检查与采用条件

检查针对当前标题、正文版本及本期约束，原文比对在独立上下文执行。字面与语义工具用于定位疑似重合；常见措辞、公共事实和常见结构需区分处理。模型判断显示理由，不伪装成确定的法律结论。

| 结果级别 | 例子 | 对操作的影响 |
| --- | --- | --- |
| 必须处理 | 未完成正文、事实占位符、明确禁用词、缺少来源的具体经历 / 数字 / 证言、未解决的明显原文独特表达沿用 | 保留草稿与问题定位；解决并重新检查后再交接 |
| 需要人工判断 | 疑似沿用独特案例安排或论证组合、材料来源待核实 | 提供具体片段与理由，允许补充依据或重构；问题处理记录与稿件版本关联 |
| 建议优化 | 语气偏差、部分句子偏长、时长偏差、结尾互动不够自然 | 提供可选修改，不强制阻止采用 |

需要人工判断的问题可通过补充依据、修改内容或标明合理引用来处理，再检查。纯粹的模型相似分数不得单独作为交接阻断依据。已知问题不通过添加无关内容或机械替换词语来降低指标。

具体事实可追溯到素材，用户提供资料与外部已核实资料保留区别。普通观点与公共常识可以正常表达，不要求用户给每句口播创建资料卡。检查不能保证发现所有错误，界面避免绝对保证。

最终采用的是完成全部文本处理后的正文。去 AI 味、校准时长、局部修订及人工编辑造成的修改，均使旧检查失效或更新检查范围。

## 9. 视频制作交接

交接快照包含新标题、分段 / 分章正文与大纲、目标平台和时长、语速与视角、本期风格快照、制作画幅，以及复创草稿与稿件版本标识。参考原文和详细分析保持在复创模块，不作为制作稿写入文案概要。

正文版本和交接设置分别记录。仅修改制作画幅时，正文版本与已有文案检查仍有效，产生新的交接设置快照；已有项目使用「更新制作设置并打开」处理。

第一次采用时，创建带完整稿件的项目，继续套用默认制作预设中的音色、字幕和画面风格。本期明确选择的平台画幅优先于默认预设的输出设置；默认画幅为短口播 9:16、中长口播 16:9，用户修改的画幅优先。跳到制作页后从断句标注开始，按现有制作流程继续。

同一复创草稿、同一稿件版本和相同交接设置重复采用，复用同一个关联项目。保存和项目创建成功后才跳转；失败或重复点击不产生重复项目。已关联项目只有制作设置改变时仍复用该项目。

原项目已采用后，复创中的编辑先形成新稿，不自动覆盖制作正文。再次交接使用「同步新版文案」，展示已有断句、配音、分镜与成片的更新影响。正文已在制作项目中人工改动时，以正文和上一采用版本的差异判断，提供「保留原制作并新建项目」与明确的同步选择，不仅用项目 revision 判断。

同步到原项目时保留旧文案与已有成片版本，更新正文并标记受影响制作结果需要更新；后续制作由既有开工与成片操作触发。复创页提供关联制作入口，制作页提供返回来源草稿入口。

## 10. 验收标准

以下为实现阶段的验收用例，本轮未执行。

| 编号 | 操作 / 场景 | 可观察的通过条件 |
| --- | --- | --- |
| A01 | 首页选爆款复创，空输入进入；再测试已有参考稿进入 | 均进入独立页面；已有文本完整带入；不产生模型调用；其他首页模式正常 |
| A02 | 参考稿 / 主题为空或仅空白，平台未选，时长无效 | 字段级提示明确；快捷提交不能启动；已有输入保留 |
| A03 | 粘贴超出参考稿或素材上限的文本 | 显示明确上限与当前长度；输入保留；不会静默截断或处理部分内容 |
| A04 | 填写参考稿、主题、平台，使用默认时长与风格提交 | 一次提交自动到完整稿，无需逐步确认；素材可为空；默认只生成一篇全文 |
| A05 | 素材未提供个人经历、成绩、证言和统计 | 输出不凭空生成这些具体事实；风格示范中的数字或故事不作为本期事实搬入 |
| A06 | 看快捷结果 | 正文是主要内容；显示标题、口播字数和预计时长；报告默认折叠；可以编辑或采用 |
| A07 | 工作台只提供参考稿 | 可先拆解；角度生成前明确要求本期主题与平台等必要信息 |
| A08 | 对同一任务生成三项候选角度 | 核心问题、证据路线或展开方式有可解释差异；素材依据可查看；不是只换开头 |
| A09 | 选择并修改角度、证据路线和大纲后成稿 | 正文使用当前选择与编辑内容；旧稿可恢复；正文只含可朗读内容 |
| A10 | 快捷任务运行中往返切换模式 | 任务 ID、阶段、已生成文本不变；没有新增模型调用；任务继续既定计划 |
| A11 | 编辑主题、素材或风格；仅保存不点生成 | 已有结果保留并正确显示旧设置状态；没有自动模型调用；选择角度不会被换掉 |
| A12 | 修改风格后更新正文 | 参考拆解与用户角度保留；采用新的本期语言规则；原检查不能冒充新稿检查 |
| A13 | 生成中刷新或离开再返回 | 恢复同一草稿、任务和阶段产物；不会重复启动已运行任务 |
| A14 | 写稿失败或停止后继续 | 原分析、角度、大纲和已完成段落保留；输入未改时只继续缺失部分；未完成稿不能进入制作 |
| A15 | 保存风格快照后在模板管理中修改模板 | 当前草稿继续使用原快照；明确重新选用后才更新；不把旧结果标成新风格结果 |
| A16 | 查看实际角度、写稿及自动修订请求 | 参考全文和独特表达未进入生成侧；生成依据是机制、本期任务、个人风格和素材 |
| A17 | 检查包含共同主题 / 公共事实的新稿，以及含明显独特表达沿用的稿 | 前者不会只因语义相近被拒；后者定位具体问题；无统一原创率或爆款概率承诺 |
| A18 | 人工编辑已检查正文，再点采用 | 检查针对当前文本版本；先保存并检查再交接；问题修订不悄悄覆盖人工文字 |
| A19 | 用同一主题分别选择抖音 / 小红书与 B站 / 西瓜 | 节奏、展开深度与结尾符合各自设置；短稿不强制采用中长稿的固定开场与投币结尾 |
| A20 | 时长偏差超过 ±15% | 显示可操作校准；修改结果可比较与恢复；估算时长不标成实际配音时长 |
| A21 | 第一次采用、连续点击采用、失败后重试 | 只产生一个对应稿件版本的制作项目；保存失败不跳转；正文与所采用快照一致 |
| A22 | 短口播采用时默认制作预设为横屏 | 新项目保留本期选择的竖屏；默认音色、字幕等其他制作设置仍按约定应用 |
| A23 | 进入制作 | 从已采用正文的断句开始；不从标题重新写稿；分析文字与原文不被读入配音 |
| A24 | 制作侧已有正文编辑，再从复创采用新版 | 能看见新版交接影响及保留旧制作选项；未执行同步前原项目不被覆盖 |
| A25 | 没有可用模型，或模型 / 保存 / 检查请求失败 | 输入与已有结果保留；错误与恢复动作就近可见；模型配置链接可用 |
| A26 | 1440px、1024px、390px 宽度与纯键盘操作 | 无横向溢出；正文与主操作可达；模式切换、折叠区和字段标签可访问；状态更新不抢焦点 |
| A27 | 复制与 Markdown 导出 | 得到当前版本标题和正文；不混入分析、检查标记或占位说明 |
| A28 | 完成首版实现 | 必要测试覆盖真实行为；`npm run typecheck`、`npm run lint` 通过；按 AGENTS.md 新增重大功能记录并确认 `/changelog` 渲染正常 |
| A29 | 写稿、修订或检查执行期间尝试编辑和采用 | 活动稿标题与正文只读；不能启动另一项写入或提前交接；查看、复制与停止仍可用 |
| A30 | 换主题或角度后仅重新检查旧稿 | 仍显示基于旧设置；需要更新受影响阶段或恢复原设置后再采用，不将旧正文标为新主题稿 |
| A31 | 抖音切 B站；自定义时长和画幅后切平台；已采用后只改画幅 | 未修改的默认值随平台更新；手动设置保持；摘要显示实际交接值；只改画幅更新关联项目设置，不重复建项目或重写正文 |
| A32 | 自动修订与人工编辑两种检查情形 | 自动修订后的报告对应新版本，仍有问题则停在需要修改；人工编辑稿不因检查被自动替换 |

质量验收还需用相同主题、素材、平台与风格，对比已有「直接写稿」流程与复创流程。人工评估吸引力、论证完整性、素材准确性、个人风格和机械改写感；不以模型自评分证明质量或传播效果。

## 11. 与现有项目的接入依据

- `components/home-composer.tsx` 已有三种首页模式，viral 是占位；正式功能需同步更新输入语义与提交行为。
- `components/workbench.tsx` 已有角度、大纲、分章成稿与局部修改能力；新模块使用这些创作能力，但新增流程须持久保存任务与阶段产物。
- `lib/types.ts` 和 `lib/templates/` 已有个人风格、事实 / 观点 / 虚构分类及大纲结构；首版补充本期素材关联、平台和风格快照。
- `lib/duration.ts` 已有口播计数、语速换算与 ±15% 时长提示口径，复创保持相同计量。
- `lib/server/jobs.ts`、`lib/pipeline/` 与 SQLite 可承载持久任务、取消和续作，首版可以复用，无需首先引入新的编排框架。
- `app/api/projects/route.ts` 创建项目时会套用默认制作预设；交接时需确保本期输出设置的优先级。
- `lib/server/versions.ts` 与项目 revision 可配合保存和恢复；需要额外建立复创草稿 / 稿件版本与制作项目的对应关系。
