## 主要行为

首页通过 sessionStorage 带入参考文本，原文不放 URL、不在入口调用模型。两模式共享可恢复草稿；快捷一次提交自动选角度并成稿，工作台允许编辑机制、任务、证据、风格、大纲和正文。

写稿只收到固定通用机制与本期任务/素材，原文及独特表达保留在分析和比对侧。检查绑定当前标题、正文与规则；自动稿最多修订一次，人工稿只产生待确认候选。

阶段 checkpoint、租约和执行代次防止迟到写入。停止以点击时的任务 ID 为目标，进度 revision 不妨碍取消，旧请求不能误停新任务。停止后手改会阻断旧续作；清空后补回完整稿可恢复完整状态，真正半稿不能冒充完整稿。版本切换/恢复/采用候选先保存编辑，再独立切换，防止串写。

真实样稿暴露的事实修订回灌与审核误引问题已修复：事实修订撤出旧角度、大纲、标题及正文中的失实锚点，只保留段落功能与时长；构造素材的性质不能省略为真实测试。原创问题需校验实际参考片段，假原文证据不成立，非逐字关联最多列为人工判断；普通类比与明确假设不应被当成虚构经历。候选角度仍是提案，推荐不宣称素材关联就代表证据充分。上述修复已通过回归和独立代码复核，真实效果尚未确认。

采用与同步使用原子事务，重复及并发请求复用项目；新版需明确同步或另建，制作正文冲突要求重新查看影响。保留旧文案和成片，从已采用正文断句进入制作，不自动开工渲染。

界面应用 Geist 排版原则与 React 技能检查，保留已有字体、暗色与亮绿体系。正文和标题随内容/宽度自动增高；手机显式快捷提交后收起输入、一次定位结果，刷新和轮询不抢焦点。

## 真实模型验收与修复

最初网络失败及自动审批 HTTP 429 后，通过正式授权完成两篇真实 Qwen 样稿，全程使用隔离 DATA_DIR，自写参考及构造素材，没有修改用户数据库或打印凭据。短稿目标 60 秒，长稿目标 180 秒。

- 修复前短稿：任务耗时 134.8 秒，最终正文预计 77.04 秒；检查标为 needs_changes。人工确认存在无依据训练词库错因、未提供的朋友对话、构造测试冒充作者实测及重复表达。审核又错误引用了不存在的参考比喻。
- 修复前长稿：任务耗时 328.9 秒，最终正文预计 166.56 秒；检查标为 needs_changes。人工初审发现虚构误删情节、构造素材失去限定及备份绝对保证，未选候选还有无依据的 90% 效果数据；最终检查把普通类比误判为故事/原创问题。两篇均没有借用参考机场比喻或风格样本 3 天/80% 数据，不能据此宣称整体原创质量已通过。
- 已完成针对性修复，并新增 5 项回归，独立内容代码复核 23/23 通过。没有新增工作流、持久字段或角度审核调用；所有候选的实质证据支持仍不能由 ID 关联自动证明。
- 修复后按相同素材复跑两篇：拆解阶段在现有结构化输出重试耗尽后均返回 AI_NoObjectGeneratedError，分别耗时 59.7 秒和 58.9 秒，没有新的正文，不能确认实际内容改善。停止继续重复模型验收，不把无输出或替身测试报告为质量通过。
