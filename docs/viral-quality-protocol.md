# 内容质量与验收样本协议

本协议区分确定性工程检查与实际模型输出评估。测试替身可以证明请求隔离、状态和证据绑定，不能证明真实原创性、吸引力或个人风格效果。

采用短科普、长科普、观点评论、商品介绍、有经历素材、明示虚构六类任务；覆盖四个平台与两种模式。参考文本使用自有文本或可用公开内容，评估时保留来源备注，不把输入授权声明当成原创保障。

每个样本记录参考、用户主题/素材、模型ID、最终标题与正文、角度/大纲、检查问题和人工处理。人工对照查看：是否有新问题和论证路线、素材是否足够、是否借用独特案例/比喻/金句、是否符合本期风格、是否可连续朗读。用具体问题定位与修改建议，不输出一个「原创率」代替判断。

工程验证使用真实临时SQLite、注入式阶段执行器和捕获模型请求，覆盖刷新恢复、失败续作、停止迟到写入、并发版本、人工稿候选和交接事务。浏览器验证使用隔离DATA_DIR，记录真实截图、路由、按钮状态与错误；必要时使用显式模拟服务完成端到端，不把模拟输出当成真实模型质量评估。

真实模型样本另列是否已执行、输出证据与未覆盖项。无可用模型时输入仍可保存且提供配置入口；不以该状态报告真实生成通过。不设置未经校准的通用相似度硬阈值，不宣称爆款概率、法律结论或风格完全复刻。
