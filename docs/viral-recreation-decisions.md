# 首版冻结决策

2026-10-11；来源为本任务用户已确认的页面规格和实施授权。

1. 名称使用「爆款复创」，由用户粘贴一篇参考稿开始，不承诺近期榜单。
2. 快捷复创自动选角度并成稿；原创工作台提供逐步决策。切换模式共享草稿、版本和任务，不增加模型请求。
3. 输出统一为视频口播稿；每次新建明确选四个平台之一。默认短口播120秒/竖屏，中长300秒/横屏；用户手动值优先。
4. 参考原文仅供拆解和比对。写作使用通用机制、用户任务、证据与风格，不沿用独特论证或案例。
5. 事实不能由风格样本、原文或模型补造。没有依据时选择无需该证据的表达；虚构需要明确选择。
6. 人工编辑受保护；检查可提供候选修订，须用户明确采用。自动稿最多自动修复一次。
7. 采用前以当前完整正文、快照和检查为准。旧设置稿不能通过重新检查直接采用。
8. 首次采用直接送入现有断句制作。重复请求复用；新版需要明确同步或新建。旧稿与旧成片保留。
9. 首版不新增抓取、转写、推荐榜单、批量多样本、微调、自动发布或新的编排框架。

产品主责为 omd-master；本文记录已确认决策，不增加新的待审批项。实现差异和证据由协调者写入实施记录。
